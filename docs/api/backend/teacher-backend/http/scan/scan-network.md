# GET /scan

扫描指定网段内的在线 IP。

---

## 基本信息

| 项目 | 值 |
|------|-----|
| 路径 | `/api/scan` |
| 方法 | `GET` |
| 服务 | `local_app`（8771） |

---

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `subnet` | string | 是 | 网段，如 `192.168.1.0/24` |

### 请求示例

```
GET /api/scan?subnet=192.168.1.0/24
```

---

## 响应示例

```json
{
  "ok": true,
  "subnet": "192.168.1.0/24",
  "ips": ["192.168.1.1", "192.168.1.101", "192.168.1.102"]
}
```

---

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `ok` | boolean | 是否成功 |
| `subnet` | string | 扫描的网段 |
| `ips` | string[] | 在线 IP 列表 |

---

## 源码位置

`packages/teacher-backend/app/api/v1/endpoints/scan.py`
